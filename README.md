# CampusTwin

CampusTwin is a digital campus management platform developed using the MERN stack.

## Features

- Student Dashboard
- Teacher Dashboard
- Admin Dashboard
- Attendance Management
- Events
- Clubs
- Marketplace
- Lost and Found
- Complaints
- Study Groups
- Skill Exchange
- Placement Tracking
- Digital ID
- Campus Map
- Chat
- Analytics

## Tech Stack

### Frontend
- React
- Vite
- React Router
- Axios
- Context API

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- Socket.io
